# assets/

Pre-rendered audio the game ships inside the Electron package: 223 tracked
files today. Everything here is optional at load time: the game runs and
plays with no `assets/` folder at all (`js/assets.js`'s own header says so),
falling back to procedural art and synthesized sound effects. Two things are
named directly; everything else is audio and is covered by GROUP lines
(clause 3 of the master file contract), since naming 223 files individually
would not help an agent pick the right one to open.

## Files directly here

- `manifest.json`: rebuilt by `npm run audio:manifest` (`tools/manifest.cjs`,
  see `tools/tools.md`). What `js/assets.js` (the runtime loader) reads to
  know what it can optionally load, and what makes the asset set data rather
  than hard-coded paths. That matters because authored art assets are
  expected to arrive through this same manifest door later, not just audio.

## Files directly under assets/voice/

- `voice/LICENSE-VOICES.md`: the attribution record for the generated voice
  audio. Auto-appended by every real (non `--dry-run`) run of
  `tools/voice/gen.py`: engine, kokoro package version, every voice id used
  that run, and the generation date. Not hand edited.

## Groups

GROUP: assets/music/*.webm (25 files) pre-rendered music stems baked by
`tools/render/` from `js/music/src/`, named `<theme>_<layer>.<hash8>.webm`.
See `tools/render/render.md` and `js/music/src/src.md`.

GROUP: assets/voice/en/brock/*.webm (72 files) Brock's spoken lines: intro,
death-by-killer (`BROCK.died`, one per killer plus a generic fallback), dawn,
idle, and every beat of `BROCK.arc`. Generated by `tools/voice/gen.py` from
`tools/voice/lines.json`; see `tools/voice/voice.md`.

GROUP: assets/voice/en/max/*.webm (37 files) barks for the internal id
`max`: runstart, boss, lowhp, chest, revive, win, death, kills, plus the
character-select line. STALE NAME, see the caveat below.

GROUP: assets/voice/en/junie/*.webm (37 files) barks for the internal id
`junie`, same category set as `max`. STALE NAME, see the caveat below.

GROUP: assets/voice/en/gus/*.webm (37 files) barks for the internal id
`gus`, same category set as `max`. STALE NAME, see the caveat below.

GROUP: assets/voice/en/qm/*.webm (8 files) the quartermaster's lines
(`QUARTERMASTER` in `js/dialogue.js`): `coins` and `idle` categories, several
slots each. Not documented by name in `tools/voice/README.md`'s speaker
summary; verified directly against `tools/voice/lines.json` instead (grep for
`"speaker": "qm"`, 8 matches).

GROUP: assets/voice/en/antlered/*.webm (1 file) one `BOSSLINES.<bossId>`
line, the antlered boss speaking for itself mid-fight.

GROUP: assets/voice/en/behind/*.webm (1 file) one `BOSSLINES.<bossId>` line
for the hidebehind boss.

GROUP: assets/voice/en/hare/*.webm (1 file) one `BOSSLINES.<bossId>` line
for the hare-named boss (BRAMBLEBUCK, per the post-effect-chain naming in

GROUP: assets/voice/en/mole/*.webm (1 file) one `BOSSLINES.<bossId>` line

GROUP: assets/voice/en/vicar/*.webm (1 file) one `BOSSLINES.<bossId>` line
for the vicar-named boss (THE TALLYMAN, per `tools/voice/README.md`).

Every count above was measured with `git ls-files 'assets/voice/en/<name>/*'
| wc -l` (and `git ls-files 'assets/music/*' | wc -l`) against the real
tracked file list, not estimated. All matched the counts given in this unit's
brief exactly; none differed.

## THE VOICE FOLDER NAMES ARE STALE

`max`, `junie`, and `gus` are internal ids for the OLD cast of three scouts.
A premise reboot has replaced that cast with five different survivors (Dez,
Junior, Vic, Hollis, Mikey per `docs/preproduction/RULINGS.md`), but nothing
under `assets/voice/en/` has been renamed, on purpose: display names and
internal ids stay separate forever in this project, so a fiction rename never
moves a folder name, a storage key, or an asset path. Do not "correct" these
folder names. `docs/preproduction/RULINGS.md` outranks any name found
anywhere in this tree, including these folder names, and is the canon to
check before assuming what a speaker id maps to today.
